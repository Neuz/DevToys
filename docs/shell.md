# 外壳

DevToys 的应用框架：主窗口、侧栏导航、设置窗口、主题与语言、托盘、全局快捷键、网络代理。功能页以插件式挂载在外壳上，各自拥有独立的配置节点、文案与后台任务。

## 主窗口

- 默认 800×550，最小尺寸相同；单实例运行，重复启动只把已有窗口带到前台。
- 隐藏原生标题栏，使用自绘标题栏：应用标题 + 副标题，右侧预留操作插槽；标题栏呈玻璃质感，内容从其下方滚过。
- 标题栏与侧栏空白处都可以按住拖动窗口。

## 侧栏导航

- 按功能页注册顺序分组显示，每组带图标与标题。
- 可折叠：展开 180 DIP、折叠 48 DIP（只剩图标轨道）；折叠按钮与设置入口固定在底部。
- 点击条目切换页面；启动时进入第一个页面。

## 设置窗口

主窗口的模态子窗口（580×480），随主窗口显示 / 隐藏，分「通用」「快捷键」「网络」三个选项卡。

- **通用**：外观、语言、开机启动、版本号与检查更新。
- **快捷键**：外壳自己的「显示 / 隐藏主窗口」全局快捷键录制。
- **网络**：代理模式与相关设置，见下文。

## 外观与语言

- 主题三档：`system` / `light` / `dark`，切换即时生效并持久化，重启保持。
- 界面语言三档：`system` / `en` / `zh-Hans`，运行时切换，主窗口与设置窗口同步刷新，托盘菜单同步更新。

## 开机启动

设置页开关直接读写系统启动项（注册表），不写入应用配置文件；开发模式下置灰不可用。

## 托盘

- 常驻托盘图标，右键菜单：显示 / 隐藏主窗口（附当前快捷键）、检查更新、退出。
- 有托盘时点击窗口关闭按钮只隐藏窗口，不退出应用。

## 全局快捷键

- 外壳注册自己的显隐快捷键，另外注册每个启用功能声明的快捷键（启动器、翻译、截图各一）。
- 取值规则：配置里没有该键 → 用功能声明的默认值；键存在但为空 → 用户显式删除，不注册；与其他绑定重复或注册失败 → 记录警告并跳过，不影响其他快捷键。
- 功能页的快捷键可在其设置页重新录制，保存后立即重绑生效。

## 网络代理

作用于 DevToys 进程内的所有 HTTP 请求（含检查更新），不修改系统代理，也不影响外部程序。

| 模式 | 行为 |
| --- | --- |
| 不使用代理 | 全部直连，忽略系统代理与环境变量 |
| 系统（默认） | 跟随当前系统代理设置（含绕过列表与 PAC） |
| 手动 | 使用填写的代理地址与例外列表，支持 http / https / socks5，可带账号密码 |

交互：

- 设置页「网络」选项卡内切换；`direct` / `system` 切换后立即生效并保存。
- 手动模式填写地址与例外（逗号分隔），点击【测试并保存】：先校验格式，再做 TCP 可达性检测（3 秒超时）。可达才保存为手动模式；不可达自动回退系统代理并提示，已填内容保留方便修改。
- 例外规则：裸域名匹配其子域；`*.example.com` 匹配通配；IP 精确匹配；CIDR 按网段；`*` 全部直连。回环地址（localhost、127.x、::1）在任何模式下都直连。
- 代理密码在日志中脱敏，不回显。

## 配置与日志

- 配置保存在用户配置目录的 `config.json`，原子写入；文件损坏时自动备份为 `config.json.bad` 并以默认值启动。
- 每个功能拥有独立的配置节点（启用开关、快捷键、私有选项），互不影响。
- 文本日志写入用户配置目录；开发模式同时输出到终端；日志目录不可写时自动降级，不影响启动。

## 更新

检查更新与安装复用 mygo 的更新器：设置页与托盘菜单均可触发，下载走当前网络代理设置。
