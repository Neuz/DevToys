# 二维码

文本实时生成二维码，可复制或保存为 PNG 图片。

## 页面

侧栏「工具」分组进入。页面上方是二维码预览（固定大小，随参数实时刷新），右侧是【保存】【复制】两个操作按钮；下方是参数设置：

| 参数 | 说明 |
| --- | --- |
| 文本 | 要编码的内容，输入即重新生成 |
| 尺寸 | 导出图片的像素大小（10–4096，默认 480）；只影响保存与复制的结果，预览不变 |
| 纠错级别 | 低 / 中 / 标准 / 高，级别越高越耐破损、可编码内容越少 |
| 前景色 / 背景色 | 二维码与底色，默认黑 / 白 |

## 输出

- **复制**：把当前参数生成的 PNG 放入剪贴板，按钮短暂显示「已复制」。
- **保存**：弹出系统另存为对话框（默认文件名含尺寸，PNG），选择位置后写入；未填扩展名时自动补 `.png`。
- 导出失败（磁盘、权限等）会弹出错误说明原因。
