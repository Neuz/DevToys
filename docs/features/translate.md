# 划词翻译

> 状态：首版已实现。取词与浮窗参考 [anghunk/glide](https://github.com/anghunk/glide)，按 DevToys 的契约裁剪。
>
> 范围：Windows；不做 OCR、自动划词、截图取词与 macOS / Linux 取词。

## 1. 参考项目 glide 的要点

glide 是一个原生 Go + MyGo 的独立划词翻译工具，和本项目技术栈一致。它的功能面包括：划词/输入/剪贴板/截图 OCR 四种入口、原生浮窗、多渠道并行对照、历史、配置备份、托盘常驻。

本次只借鉴取词与浮窗，其余按下面的范围裁剪：

| 能力 | glide 的做法 | 本项目 |
| --- | --- | --- |
| 取词 | Windows 用 UI Automation 的 `TextPattern.GetSelection` 读取前台窗口选区；不模拟按键、不读写剪贴板 | 借鉴（仅 Windows） |
| 取词健壮性 | 前台窗口 PID 过滤自身；最多向上找 6 层祖先；跳过密码框；UIA 连接/事务各 700ms 超时；外层 3s；单并发槽防卡死 | 全部借鉴 |
| 浮窗 | `mygo.NewWindow` 的 `Panel + Frameless + Hidden + CornerRadius`；靠近鼠标定位并按工作区夹紧；失焦隐藏；固定后保留；结果区滚动 | 借鉴 |
| 自动划词 | 只读鼠标钩子 + 去抖 + 超时 | 不借鉴 |
| 多渠道 | 渠道并行、独立结果与错误、可配置顺序 | 借鉴并行与独立错误 |
| OCR / 历史 / 备份 / 托盘 | 独立功能 | 不做 |

## 2. 产品范围

### 首版（P1）

1. 选中文本后按 `Alt+T`：读取选区，浮窗自动填入原文并立即翻译。
2. 没有选区时按 `Alt+T`：浮窗打开并聚焦输入框，输入后自动翻译（600ms 去抖），`Ctrl+Enter` 立即翻译。
3. 同时启用一个或多个翻译服务，结果按启用的顺序展示；单个服务失败不影响其他服务。
4. 浮窗支持编辑原文重译、复制译文、单服务重试、折叠结果、源/目标语言互换、固定、`Esc` 关闭。
5. 侧栏「翻译」页用于启用服务、选择目标语言与录制快捷键；所有配置放在 `features.translate` 节点。
6. 主题与界面语言跟随外壳，浮窗同步。

### 明确不做

- 自动划词、鼠标钩子、剪贴板监听。
- 图片 OCR、截图取词、文件/文档翻译。
- 朗读（TTS）、词典释义、音标。
- macOS / Linux 跨应用取词。
- 历史记录、云同步。

## 3. 交互设计

### 快捷键

只保留一个全局快捷键，通过 `contract.GlobalHotkeyer` 声明，默认 `Alt+T`，保存在 `features.translate.hotkeys.translate`。

- 空字符串表示用户显式删除，不回退默认值（与启动器一致）。
- 注册失败只记 warn，并在翻译页显示当前绑定。
- 浮窗已打开时再次按快捷键：重新读取选区；有选区则替换并翻译，无选区则保持当前内容。

### 触发流程

```
按下 Alt+T
  ├─ 取前台窗口选区（最多 3s）
  ├─ 有文本：打开浮窗 → 填入原文 → 自动翻译
  └─ 无文本：打开浮窗 → 聚焦输入框 → 用户输入 → 600ms 后自动翻译
```

- **先读选区，再显示浮窗**：避免浮窗抢走前台焦点导致 UIA 读到自己。
- 输入框内容变化时递增 generation、取消上一轮请求；只有最后一次输入的结果会显示。
- 输入为空不发请求；纯空白视为空。
- `Ctrl+Enter` 立即翻译；`Esc` 关闭；复制按钮复制对应服务译文。

### 浮窗（参照启动器面板风格）

- 复用启动器的 `Panel + Frameless + Hidden + CornerRadius`，相同的圆角、间距、字体层级与控件样式。
- 宽 400 DIP；高度固定 560 DIP，工作区过矮时按 80% 收缩且不低于 400 DIP；结果超出后由结果区滚动，窗口不再随内容改变高度。
- 顶部工具行可拖动窗口：左侧固定/取消固定，右侧关闭；拖动请在工具行空白处按住。
- 原文输入框为多行：3 行起随内容增高，最多 6 行，再多则在框内滚动；选中文本进入面板时自动全选，直接输入即可替换。
- 语言行：源语言下拉（自动识别 / 具体语言）、互换按钮、目标语言下拉、「翻译」按钮；源语言仅本次会话有效，目标语言随设置持久化。
- 结果卡片：服务图标 + 名称 + 折叠按钮；正文可选中复制；底部显示「检测到语言 · 耗时」，右侧为重试与复制图标。
- 底部固定提示：`Ctrl+Enter` 立即翻译、`Esc` 关闭。
- 定位：默认跟随鼠标，光标右下偏移 16/20；靠近屏幕边缘时翻到左侧/上方并夹紧到工作区；关闭「跟随鼠标」时在显示器居中。
- 失焦即隐藏；「固定」后不自动隐藏，直到取消固定或按 `Esc`。

```
┌──────────────────────────────────────┐
│ [固定]───── 拖动区域 ────────  [×]   │
│ ┌──────────────────────────────────┐ │
│ │ 原文……                           │ │
│ │                                  │ │
│ └──────────────────────────────────┘ │
│ [自动识别▾] [⇄] [智能互译▾]  [翻译]  │
│ ┌──────────────────────────────────┐ │
│ │ ◎ Google                    [⌃] │ │
│ │ 译文……                           │ │
│ │ 检测到英语 · 266 ms       [↻] [⧉] │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ ◎ 哔哩哔哩                   [⌃] │ │
│ │ 译文……                           │ │
│ │ 检测到英语 · 342 ms       [↻] [⧉] │ │
│ └──────────────────────────────────┘ │
│ Ctrl+Enter 立即翻译 · Esc 关闭        │
└──────────────────────────────────────┘
```

### 取词失败

| 情况 | 浮窗表现 |
| --- | --- |
| 没有选区 | 不提示错误，直接聚焦输入框等待输入 |
| 当前系统不支持 | 输入框上方提示「当前系统暂不支持跨应用取词，可手动输入」 |
| 高权限或自绘窗口拒绝 | 提示「该窗口不允许读取选区，可手动输入或复制原文」 |
| 超时 | 同样进入输入模式，并提示「读取选区超时」 |

## 4. 技术架构

所有取词代码也放在功能包内，不新增 `internal/selection`：

```
internal/features/translate/
  module.go              契约实现、配置、快捷键、生命周期
  panel.go               浮窗创建、定位、显隐、固定与面板 UI
  view.go                侧栏设置页
  selection.go           选区类型、错误、超时与单并发槽
  selection_windows.go   UI Automation 实现
  selection_other.go     unsupported 实现
  service.go             配置解码、语言决策、并行调度、request generation
  provider.go            Provider 接口与 Request/Result（约束层）
  google.go              Google：自带 HTTP 客户端拼装与错误处理
  bilibili.go            哔哩哔哩：自带 HTTP 客户端拼装与错误处理
  locales/               本功能中英文文案
```

- 只依赖 `contract`、`config`、`network`、`task` 与标准库，不 import `shell`。
- 实现 `Module`、`Toggleable`、`GlobalHotkeyer`、`Closer`，契约无需扩展。
- 浮窗生命周期复用启动器模式：首次需要时创建、隐藏不销毁、`OnClose` 只隐藏、`Close()` 统一销毁并取消请求。

### 取词（Windows）

1. 取前台窗口与 PID；等于自身则视为无选区。
2. 锁定 OS 线程后 `CoInitializeEx(COINIT_MULTITHREADED)`，创建 `IUIAutomation2`；可用时设连接/事务超时各 700ms，否则退回 `IUIAutomation`。
3. 取焦点元素，最多向上 6 层祖先，任一层用 `GetCurrentPatternAs(UIA_TextPatternId)`。
4. 跳过 `IsPassword`；`GetSelection` 合并最多 8 段，单段上限 100000 字符。
5. 取鼠标位置作为浮窗锚点；再次确认前台窗口未变化。
6. 逐层释放 COM 接口；容量 1 的槽位串行化读取；外层 3s 超时。
7. 非 Windows 编译为 `ErrUnsupported`，只保留手动输入与设置页。

## 5. 翻译服务

### 接口

```go
type Request struct {
    Text   string
    Source string // auto 或语言标签
    Target string
}

type Result struct {
    Provider string
    Text     string
    Detected string
    Latency  time.Duration
}

type Provider interface {
    ID() string
    Name() string
    Translate(ctx context.Context, req Request) (Result, error)
}
```

- 纯函数式、无 UI 依赖，便于 `httptest`。
- HTTP 统一使用 `network.Client()`，遵循应用代理；单服务超时 10s，整体 15s。
- 启用多个服务时并行启动；结果按设置页顺序稳定排列；先完成先显示。
- 每次新请求递增 `generation` 并取消旧 `context`，过期结果丢弃。
- 同一服务不自动重试；用户可点「重试」。

### 渠道

| 服务 | 实现 | 密钥 | 限制与风险 |
| --- | --- | --- | --- |
| Google | `POST https://translate.googleapis.com/translate_a/single`，表单 `client=gtx&sl=auto&tl=…&dt=t&q=…` | 无 | 非官方接口；中国大陆通常需要代理；单次 ≤ 5000 字符 |
| 哔哩哔哩 | `POST https://index-translate.bilibili.com/v1/chat/completions`，`model=Index-Translate-35B-A3B`，OpenAI 兼容，无需鉴权 | 无 | 免费公网接口，可能限流或调整；单次文本 ≤ 4000 字符，`max_tokens` 2048 |

哔哩哔哩请求要点：

- `messages` 只放一条 `user`，中文提示词：`请将以下文本翻译为{目标语言}，直接输出翻译结果，不要进行任何解释。\n\n{原文}`；已知源语言时替换「以下文本」为「以下{源语言}文本」。
- `temperature: 0`、`max_tokens: 2048`、`chat_template_kwargs: {"enable_thinking": false}`；响应若含 `</think>` 则截断保留后半段。
- 兼容 OpenAI 的 `choices[0].message.content`；非 2xx 读取错误体并截断，作为该服务的独立错误展示。

### 语言

- 源语言默认自动检测，只用本地启发式：假名 → `ja`；韩文 → `ko`；仅汉字 → `zh-Hans`；西里尔 → `ru`；其余拉丁 → `en`。
- 浮窗语言行可手动指定源语言；该选择只在本次会话有效，重新呼出仍回到自动识别。
- 目标语言默认「自动」：检测为中文时译成 `en`，否则译成 `zh-Hans`。
- 用户显式选择目标语言后始终以配置为准；源目标相同则交换为中文/英文。
- 各服务做语言码映射：Google `zh-CN`、哔哩哔哩使用中文语言名（简体中文、English、日本語等）。

## 6. 设置页

侧栏「翻译」页，沿用启动器的设置页风格与 `SettingsGroup`：

- 服务：Google、哔哩哔哩两个开关，可只启用一个或多个；全部关闭时显示「至少启用一个服务」。
- 目标语言：自动 / 简体中文 / English / 日本語 / 한국어 / …
- 浮窗：跟随鼠标。
- 快捷键：一个 `form.HotkeyInput`，保存后调用 `Host.HotkeysChanged()` 立即重绑。
- 隐私提示：原文会发送给已启用的服务。

默认值：哔哩哔哩启用，Google 关闭；用户可在设置页按需打开一个或多个。

## 7. 配置

全部放在外壳配置的功能节点中，不新增配置文件：

```json
{
  "features": {
    "translate": {
      "enabled": true,
      "hotkeys": {
        "translate": "Alt+T"
      },
      "options": {
        "target": "auto",
        "panel_follows_cursor": true,
        "providers": {
          "google": false,
          "bilibili": true
        }
      }
    }
  }
}
```

- 用 `config.DecodeOptions` 解码到带默认值的 `options`；缺失字段保留默认。
- 保存失败时回滚内存值并提示，与启动器一致。
- 快捷键沿用功能节点自己的 `hotkeys` map，由外壳统一注册。
- 日志只记录服务、耗时与错误信息，不记录原文或译文。

## 8. 文案、主题与线程

- 文案放 `locales/zh-Hans.json`（带 `@description`）与 `en.json`，纳入 `i18n check`。
- 浮窗与设置页都调用 `theme.Apply(c)`；界面语言由 `mygo.App.Locale()` 驱动。
- UI 状态只在主线程读写；UIA 读取与 HTTP 请求都在 goroutine，结果经 `mygo.RunOnMain` 回主线程。
- 输入去抖用 `time.AfterFunc` 或可取消 timer；关闭浮窗与退出时停止 timer、取消请求。

## 9. 隐私与安全

1. 只有按下快捷键或输入文本时才读取选区、发起请求；启动时不读。
2. 不模拟按键、不修改剪贴板、不装鼠标/键盘钩子。
3. 密码框拒绝读取；读取前后校验前台窗口，避免误读自身。
4. 原文会发送给已启用的服务（Google / 哔哩哔哩），设置页必须明示。
5. 日志不记录原文与译文。
6. 请求统一走 `network.Client()`，遵循代理与例外；不自行读取环境变量。
7. 高权限窗口读不到时提示手动输入，不做提权。

## 10. 测试与验收

### 单测

- `service_test.go`：汉字/假名/韩文/西里尔/拉丁检测、显式源语言、目标语言决策与互换。
- `provider_test.go`：多服务并行顺序稳定、单服务失败不影响其他、取消后不回调、空文本与超长文本拒绝；`httptest` 覆盖 Google 与哔哩哔哩的请求参数、错误响应与 `</think>` 截断。
- `panel_test.go`：边缘翻转、工作区夹紧与固定高度（纯函数）。
- `options_test.go`：默认值、缺失字段、非法服务组合回退。

### 手动验收

| 场景 | 期望 |
| --- | --- |
| 记事本选中文字按 `Alt+T` | 浮窗填入原文并自动翻译，显示已启用的服务 |
| 无选区按 `Alt+T` | 浮窗打开并聚焦输入框；输入后 600ms 自动翻译 |
| 连续快速输入 | 只显示最后一次输入的结果，旧请求取消 |
| 拖动顶部工具行 | 浮窗跟随移动；固定/关闭按钮仍可点击 |
| 长译文或多服务 | 结果区出现滚动条，卡片不被裁切；新原文自动滚回顶部 |
| 点击卡片折叠按钮 | 只收起该卡片正文，再次翻译后保持该服务的折叠状态 |

| Chrome / Edge 网页选区 | 可读取；浮窗不抢焦点导致第二次失败 |

| 双屏、靠右下角触发 | 浮窗翻转并夹紧在工作区 |
| 固定后点击别处 | 浮窗保留；取消固定后失焦隐藏 |

### 自动检查

`gofmt -l cmd internal`、`go vet ./...`、`go test ./...`、`go tool mygo i18n check .`。

项目保持 `CGO_ENABLED=0`，不引入 cgo 依赖；并发安全由互斥锁、generation 校验与 context 取消共同保证，不使用依赖 cgo 的 race detector。

## 12. 风险与取舍

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| UIA 覆盖不全 | 部分应用取不到选区 | 直接进入输入模式，不弹错误对话框；验收矩阵持续补充 |
| Google 非官方接口 | 大陆无代理时不可用或变更 | 应用代理已可覆盖；服务可关闭；错误只影响该卡片 |
| 哔哩哔哩免费接口 | 限流、排队或调整 | 独立错误展示；可只启用其他服务；不自动重试 |
| 全局快捷键冲突 | 无法呼出 | 外壳已检测重复并 warn；设置页可改键 |
| 浮窗抢焦点 | 第二次取词读到自身 | 先读选区再 Show；前台 PID 过滤自身 |
| 大文本 | 缓慢或失败 | 各服务字符上限；15s 总超时；可取消 |

## 13. 与现有约束的对应

- 设置页可维护多个服务开关，配置全部落在 `features.translate`，不引入独立配置文件。
- 不修改外壳契约：只实现 `Module`、`Toggleable`、`GlobalHotkeyer`、`Closer`。
- 不新增依赖：UIA 用 `syscall` 调用系统 COM；HTTP 用标准库与 `network.Client()`。
- 依赖方向保持 `app → shell → contract ← features`。
- 业务错误显式返回并带上下文，不用 panic。
