# 划词翻译

选中任意应用的文本后按快捷键，浮窗即时给出多服务对照翻译；没有选区时进入手动输入模式。

## 唤起

- 默认全局快捷键 `Alt+T`（可改可删）。
- 按下后先读取前台窗口的选中文本，再显示浮窗：
  - 有选区：原文自动填入并立即翻译。
  - 无选区（或读取失败）：浮窗聚焦输入框，等待手动输入；输入停顿约 600ms 自动翻译，`Ctrl+Enter` 立即翻译。
- 浮窗已打开时再按快捷键：重新读取选区，读到则替换并翻译。
- 只读方式取词：不模拟按键、不读写剪贴板、不装钩子；密码框一律不取。

## 浮窗

宽 400 的无边框置顶浮窗，风格与启动器面板一致：

- **定位**：默认出现在鼠标右下方，靠近屏幕边缘自动翻转并夹紧到工作区；关闭「跟随鼠标」后居中显示。
- **拖动**：按住顶部工具行空白处可移动。
- **固定**：默认失焦即隐藏；点【固定】后常驻，直到取消固定或 `Esc` 关闭。
- **原文区**：多行输入框，可修改原文触发重译；带选区进入时自动全选，直接输入即可替换。
- **语言行**：源语言（默认自动识别，可手动指定，仅本次会话有效）、互换按钮、目标语言、「翻译」按钮。
- **结果卡片**：每个启用的服务一张卡片，显示译文（可选中复制）、检测到的语言与耗时；支持单服务重试、复制译文、折叠正文。新原文自动滚回顶部。
- 底部提示：`Ctrl+Enter` 立即翻译、`Esc` 关闭。

## 翻译服务

- 内置两个服务：Google、哔哩哔哩，可同时启用多个，结果并行请求、按设置顺序稳定排列，先完成先显示。
- 单个服务失败只显示在该卡片上（可重试），不影响其他服务。
- 输入变化或重新触发会取消上一轮请求，只显示最新结果。
- 语言自动规则：中文文本译成英文，其他语言译成中文；目标语言可在设置页显式指定。

## 设置页

侧栏「翻译」进入：

- 服务开关（至少启用一个）。
- 目标语言。
- 浮窗跟随鼠标开关。
- 快捷键录制。

所有请求遵循外壳的网络代理设置；日志不记录原文与译文。
