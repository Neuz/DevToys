# 截图

QQ 截图式的全屏截图工具：快捷键冻结屏幕，框选或点选区域，标注后写入剪贴板或保存文件。

## 唤起与选区

- 默认全局快捷键 `Ctrl+Alt+A`（可改可删），可在设置页关闭整个功能。
- 按下后整个虚拟桌面（所有显示器）瞬间冻结为静态画面，覆盖半透明蒙版，可识别的窗口轮廓以蓝色高亮边框提示。
- **拖拽框选**：按住左键拖动，实时显示选框与左上角尺寸标签（宽×高）。
- **点选窗口**：单击直接吸附某个窗口边界（按窗口实际可见轮廓，不含系统隐形调整边框；最小化、虚拟桌面隐藏、工具窗口等不可见窗口不参与）。
- 拖动小于 3px 视为误触，取消截图。

## 选区调整

选区确定后（进入标注状态）：

- **改尺寸**：选区边框上有四角 + 四边共 8 个手柄，按住任意手柄拖动即可调整，实时显示新尺寸；选区不会小于最小尺寸，也不会超出屏幕。
- **整体移动**：在不选择任何标注工具的状态下（默认状态，或再次点击已激活的工具取消选择），在选区空白处按住拖动即可平移整个选区。

## 标注

选区下方浮动两段工具栏：主工具栏（工具 + 操作），子工具栏（当前工具的属性）。

主工具栏从左到右：矩形、椭圆、划线、箭头、画笔、马赛克、文本；分隔后是撤销、重做；再分隔后是保存、完成、取消。

### 形状绘制

所有形状类工具（矩形 / 椭圆 / 划线 / 箭头 / 画笔 / 马赛克）交互一致：按下确定起点，拖动实时预览，松开固化。再次点击已激活的工具可取消选择，回到可移动选区的状态。

| 工具 | 说明 |
| --- | --- |
| 矩形 / 椭圆 / 划线 / 箭头 | 基础形状，粗细与颜色在子工具栏设置 |
| 画笔 | 自由曲线，粗细与颜色同上 |
| 马赛克 | 两种模式在子工具栏切换：涂抹（沿笔迹打码，粗细控制笔刷半径）/ 框选（默认，拖矩形，松开后框内打码，打码严格限制在框选范围内） |
| 文本 | 点击选区内位置就地输入，Enter 确认，Esc / 点击别处取消；子工具栏可改字号与字色 |

### 子工具栏

- 形状 / 画笔 / 马赛克：粗细滑杆（1–12）+ 当前值 + 颜色色板（6 个预设色）。
- 马赛克额外提供涂抹 / 框选模式切换按钮。
- 文本：字号滑杆（1–48）+ 当前值 + 字色色板。
- 未选择工具时子工具栏隐藏。

### 标记的选择与移动

在不选择任何标注工具的状态下：

- 点击已画好的标记（形状、马赛克、文本）即选中，出现高亮框。
- 按住拖动可移动标记，移动范围限制在选区内。
- 点击空白处取消选中。

### 撤销 / 重做

每次固化（含文本提交、删除）压入撤销栈；撤销移出的标记可重做。

## 输出

| 操作 | 触发 | 行为 |
| --- | --- | --- |
| 完成 | `Enter` 或工具栏按钮 | 合成图像（选区 + 全部标注）写入剪贴板，退出截图 |
| 保存 | `Ctrl+S` 或工具栏按钮 | 弹出另存为对话框（PNG），保存后退出；取消对话框同样退出 |
| 取消 | `Esc` 或工具栏按钮 | 逐级退出：正在输入文本 → 只取消文本；已选工具 → 只取消工具；默认状态 → 退出截图 |

右键在任何阶段都直接取消整个截图。

## 设置页

侧栏「截图」进入：功能启用开关与触发快捷键录制。关闭后快捷键不再响应。
