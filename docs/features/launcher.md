# 启动器

全局快速启动面板：快捷键唤起置顶浮层，输入关键字查找并启动开始菜单应用或 Windows 系统设置页。

## 唤起与面板

- 默认全局快捷键 `Alt+F`（可改可删）。
- 面板为无边框置顶浮窗，出现在鼠标所在显示器工作区中央略偏上的位置；宽 680，高度随结果行数自适应。
- 首次唤起时创建，之后隐藏复用；失焦约 100ms 后自动隐藏（期间重新聚焦则保持显示）；关闭按钮只隐藏不销毁。

## 搜索

- 空查询只显示搜索框；输入后出现结果列表与【全部 / 应用 / 系统】分类页签。
- 查询按空格分词，每个词都需命中（不区分大小写）；支持中文标题、英文名、可执行文件名、拼音全拼与首字母，如 `jsq` 可搜到「计算器」。
- 结果数量可配置（默认 8），超出后列表内部滚动。
- 排序按使用频率：启动过的应用靠前（次数 → 最近使用），未用过的按标题；只有启动成功才记使用。

## 键盘操作

- `↑` `↓` 移动高亮，`Enter` 启动高亮项并隐藏面板。
- `Esc`：查询非空时先清空查询，空查询时隐藏面板。
- 列表由搜索框驱动，Tab 不会落入列表。

## 索引内容

- 开始菜单中的桌面应用与打包应用（UWP）。
- 内置条目：31 个常用系统设置页（归入「系统」分类）、远程桌面等系统程序。
- 默认排除「卸载 / 帮助 / 说明 / 文档」类快捷方式，排除词可在设置页编辑。
- 启动时先用上次缓存的索引（首帧即可用），后台静默重建并替换；也可在设置页手动【重建索引】，完成后弹提示。

## 设置页

侧栏「启动器」进入：

- 启用开关：关闭后快捷键不再响应。
- 触发快捷键：录制框，清空即删除。
- 显示结果数量。
- 【触发】按钮：直接打开面板。
- 【重建索引】按钮与排除关键词编辑。

图标取应用真实图标（按显示缩放），取不到时用名称首字头像；系统设置条目固定用设置图标。
