# 需求与范围

## 产品定位

DevToys 是一套「功能会持续增加」的桌面开发工具箱骨架，而不是一次交付的固定工具集。核心诉求是外壳稳定、功能可插拔：新增工具页不修改窗口、导航与设置框架。

- 当前版本：`0.0.1`（见 [mygo.json](../mygo.json)）
- 技术栈：Go 1.27+、[mygo](https://github.com/egoist/mygo) 原生窗口、[mygoui](https://github.com/Cyenoch/mygoui) 组件库
- 主要平台：Windows（开始菜单索引与 `ms-settings:` 入口为 Windows 专属）

## 功能清单

优先级：P0 = 骨架成立与日常可用所必需；P1 = 体验完善；P2 = 示例或后续规划。

### 外壳（P0，已完成）

| 能力 | 需求 |
| --- | --- |
| 主窗口 | 800×550，最小尺寸同值；隐藏原生标题栏，内容铺满窗口；单实例运行 |
| 侧栏导航 | 按模块 `Group()` 分组；展开 180 DIP、折叠 48 DIP；折叠按钮与底部设置入口；空白处可拖动窗口 |
| 自绘标题栏 | 应用标题（副标题由 `Options.Subtitle` 提供，可留空）；右侧预留操作插槽；跟随文字缩放调整高度；内容从其下方滚过 |
| 设置窗口 | 主窗口的模态子窗口（580×480），随主窗口显示/隐藏；「通用」「快捷键」两个选项卡 |
| 外观 | `system` / `light` / `dark`，启动首帧即生效，修改后即时应用并持久化 |
| 语言 | `system` / `en` / `zh-Hans`，运行时切换，主窗口与设置窗口同步刷新 |
| 托盘 | 右键菜单：显示/隐藏主窗口（右侧显示当前快捷键）、检查更新、退出；有托盘时关闭主窗口仅隐藏 |
| 全局快捷键 | 外壳窗口显隐 + 各启用功能声明的快捷键；重复或注册失败只记录 warn，不阻断其他绑定 |
| 开机启动 | 设置页开关直接读写系统状态，不写入 `config.json`；开发模式置灰 |
| 配置 | `config.json` 原子写入；缺失时用默认值；损坏时备份为 `.bad` 后回退默认值 |
| 日志 | `slog` 文本日志写入用户配置目录；开发模式或 `debug` 级别同时输出 stderr；不可写时降级且不阻止启动 |

### 功能扩展机制（P0，已完成）

| 能力 | 需求 |
| --- | --- |
| 契约 | `contract.Module` 为必需；`Live`、`Toggleable`、`GlobalHotkeyer`、`Closer` 按需实现 |
| 运行时设施 | 每个功能获得独立的配置节点、带模块标识的日志器与后台任务 runner |
| 文案隔离 | 每个功能自带 `locales/` 目录与 `T(key)` 入口，key 不需要模块前缀 |
| 注册方式 | 编译期注册：在 [app.go](../internal/app/app.go) 的模块列表中新增一行，无需改动外壳 |

### 启动器（P0，已完成）

| 能力 | 需求 |
| --- | --- |
| 唤起 | 默认 `Alt+F`；可在设置页重新录制；清空表示显式删除，不回退默认值；禁用后不注册快捷键 |
| 索引 | 开始菜单全部应用 + Windows 设置页与系统程序内置条目；按 ID 与标题去重 |
| 搜索 | 多词 AND 匹配标题与关键词；关键词含别名、exe 名、拼音全拼与首字母 |
| 排序 | 按使用次数、最近使用时间降序，再按标题长度与字典序；结果数量可配置 |
| 面板 | 无边框置顶浮层；空查询仅显示搜索框；方向键 / 回车 / `Esc` 操作；失焦延迟隐藏 |
| 持久化 | bbolt 保存索引与使用记录；启动先读缓存，随后后台重建 |

详细行为见 [启动器](features/launcher.md)。

### 示例页（P2，非产品功能）

`welcome` 页用于演示 `contract.Module`、`task.Runner` 与 `slog` 的用法，不承载产品需求，也不作为功能文档对象。

## 明确的非目标

以下内容在可预见的版本内不做，或明确不在本仓库范围内：

- **不做工具搜索 / 命令面板**：导航就是侧栏列表，不提供搜索框。
- **不做命令行模式**：`cmd/` 只有桌面入口，不提供子命令。
- **不做插件热加载**：功能在编译期注册，不支持运行时发现或动态加载。
- **不做配置迁移**：旧的扁平快捷键键 `hotkey_global` / `hotkey_sidebar` 不再读取，升级后需重新录制。
- **不做日志轮转**：日志持续追加，由用户自行清理。
- **不做跨平台适配承诺**：托盘、开始菜单索引、`ms-settings:` 等以 Windows 为准，macOS / Linux 未验证。
- **不做侧栏宽度自定义**：展开与折叠宽度是常量，不写入配置，也不可拖动调整。
- **不做功能设置集中页**：功能开关与其私有配置由各功能自己的页面管理。
- **不自定义更新流程**：检查更新与安装复用 `mygo` 的 updater 插件。

## 验收基线

- `gofmt -l cmd internal locales resources` 无输出，`go vet ./...`、`go test ./...`、`go tool mygo i18n check .` 通过。
- 重复启动只保留一个实例，第二个进程直接退出。
- 主题与语言切换立即作用于主窗口与设置窗口，重启后保持。
- 启动器可通过快捷键唤起，能用中文、拼音全拼、首字母命中并启动应用。
- 新增工具页只需新建包并在 `setupModules()` 中注册一行。
